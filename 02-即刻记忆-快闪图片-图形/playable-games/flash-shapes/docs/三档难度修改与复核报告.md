# 快闪图形·三档难度修改与复核报告

## 1. 修改结论

已在成人版和儿童版训练入口加入三档难度：

| 难度 | 起始关卡 | 运行标识 |
|---|---:|---|
| 容易 | 第 1 关 | `easy` |
| 普通 | 第 15 关 | `normal` |
| 困难 | 第 30 关 | `hard` |

玩家在菜单页选择难度后再进入训练。进入训练后，游戏仍按原设计执行动态升降难度：通关 +1；失败第 1 次保持原关，第 2 次相对失败序列起始关 -1，第 3 次 -3 并清空失败计数。

## 3. 接口变化

训练结束 payload 现在增加：

```js
{
  difficultyId: "easy" | "normal" | "hard",
  difficultyLabel: "容易" | "普通" | "困难",
  difficultyStartLevel: 1 | 15 | 30
}
```

URL 启动参数支持：

```text
儿童版/index.html?trainingSeconds=300&difficulty=easy
儿童版/index.html?trainingSeconds=300&difficulty=normal
成人版/index.html?seconds=300&difficulty=hard
```

兼容参数 `startLevel`、`level` 仅识别 `1`、`15`、`30` 三个起始点，不再作为任意自定义关卡入口。

本次只改变训练入口的起始难度选择，不改变关卡配表本身，不改变 N/M 通关目标、小关结束条件、训练总时间归零结束、积分公式、通关标识传参、帮助红字、图形表、图形范围、素材加载和升降难度规则。
