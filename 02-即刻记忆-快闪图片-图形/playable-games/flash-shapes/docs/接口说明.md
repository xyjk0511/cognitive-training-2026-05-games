# 训练结束接口说明

训练结束时，游戏会构造统一结果对象 `payload`，并通过四种方式传出。核心字段如下：

```js
{
  type: "KX_TRAINING_END",
  gameId: "flash-shape",
  gameTitle: "快闪图形",
  version: "child" | "adult",
  versionLabel: "儿童版" | "成人版",
  difficultyId: "easy" | "normal" | "hard",
  difficultyLabel: "容易" | "普通" | "困难",
  difficultyStartLevel: 1 | 15 | 30,
  completed: true,          // 总训练时间到 0 时为 true；用户中止时为 false
  aborted: false,           // 用户提前返回设置时为 true
  passFlag: 1,              // 1=已通关，0=未通关
  passed: true,
  passText: "已通关",
  lastLevelPassed: true,    // 最后一小关是否通关
  startLevel: 1,
  finalLevel: 2,
  totalScore: 120,
  assignedTrainingSeconds: 180,
  usedTrainingSeconds: 180,
  remainingSeconds: 0,
  endReason: "训练时间=0",
  endedAt: "2026-05-13T00:00:00.000Z",
  history: []               // 小关记录
}
```

传出方式：

```js
// 方式 1：宿主页面定义全局回调
window.KX_onTrainingEnd = function(payload) {
  console.log(payload.passFlag, payload.totalScore);
};

// 方式 2：监听自定义事件
window.addEventListener("KX_TRAINING_END", function(event) {
  console.log(event.detail);
});

// 方式 3：iframe 宿主监听 postMessage
window.addEventListener("message", function(event) {
  if (event.data && event.data.type === "KX_TRAINING_END") {
    console.log(event.data.payload);
  }
});

// 方式 4：读取最近一次结果
const latest = JSON.parse(localStorage.getItem("KX_LAST_TRAINING_RESULT"));
```

启动传参支持 URL 参数：

```text
儿童版/index.html?trainingSeconds=300&difficulty=easy
儿童版/index.html?trainingSeconds=300&difficulty=normal
成人版/index.html?seconds=300&difficulty=hard
```

`trainingSeconds`、`seconds`、`duration`、`time` 均可指定下发训练时长；`difficulty` 可指定 `easy` / `normal` / `hard`，分别对应容易/普通/困难，并固定从第 1 / 15 / 30 关开始。兼容参数 `startLevel`、`level` 仅用于识别 1、15、30 三个起始点，不再作为任意自定义关卡入口。


## postMessage 目标域配置

默认 `postMessageTargetOrigin` 为 `"*"`，用于离线文件和未确定宿主域的验收环境。正式平台接入时，建议在启动配置中指定宿主域：

```html
<script>
window.KX_BOOT_CONFIG = {
  version: "child",
  defaultTrainingSeconds: 300,
  defaultDifficulty: "easy", // easy=第1关，normal=第15关，hard=第30关
  defaultStartLevel: 1,
  postMessageTargetOrigin: "https://your-platform.example"
};
</script>
```

指定后，训练结束消息只会发往该目标域。
