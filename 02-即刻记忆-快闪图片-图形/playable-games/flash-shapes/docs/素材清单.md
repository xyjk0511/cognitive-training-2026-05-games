# 素材清单（打磨版）

| 类型 | 路径 | 数量 | 运行中是否使用 | 说明 |
|---|---|---:|---|---|
| 图形 SVG | `assets/shapes/shape_001.svg` 至 `shape_100.svg` | 100 | 备用/兼容 | 无 `Icon` 字段时作为回退。 |
| 图形 PNG | `assets/shapes_png/shape_001.png` 至 `shape_100.png` | 100 | 备用 | 供非 SVG 场景或后续替换使用。 |
| Icon SVG | `assets/icons/Icon1.svg` 至 `Icon100.svg` | 100 | 是 | 游戏卡牌优先按图形表 `Icon` 字段加载。 |
| Icon PNG | `assets/icons_png/Icon1.png` 至 `Icon100.png` | 100 | 备用 | 与 Icon SVG 一一对应。 |
| UI SVG/PNG | `assets/ui/` | 40 | 部分直接使用 | 背景、按钮、HUD 图标、帮助页、结果面板、标题、手指提示。 |
| 小康康 SVG/PNG | `assets/mascot/` | 12 | 是 | idle、wave、happy、blink、think、sad 六种状态。 |
| 音频 WAV | `assets/audio/` | 7 | 是 | click、correct、wrong、level_start、success、fail、bgm_loop。 |
| 图形总览 | `assets/atlas/shape_contact_sheet.png` | 1 | 预览 | 供素材检查。 |
| 素材清单 JSON | `assets/ASSET_MANIFEST.json` | 1 | 文档/验收 | 记录素材数量与映射。 |

## 替换规则

官方图形切图到位后，优先替换 `assets/icons/Icon*.svg` 或 `assets/icons_png/Icon*.png`。当前运行代码读取 `shared/data.js` 的 `shape.Icon`，再拼接为 `assets/icons/{Icon}.svg`。

若官方仍按 `shape_001.svg` 命名，也可删除 `Icon` 字段或在 `resolveIconSrc()` 中切换回 `assets/shapes/shape_###.svg`。
