# 快闪图形·打磨版 修复与复核报告

## 1. 修复范围

本次修复对象为 `快闪图形_精致版_完整游戏包.zip` 解压后的游戏包。修复后输出为 `快闪图形_打磨版_完整游戏包.zip`。

修复重点：

1. 通关标识真实传出，而不是只在界面显示。
2. 训练通关或小关结束后自动继续，直到总训练时间为 0。
3. 每关显式 `TargetCount` 与 `ShapeRange` 字段生效。
4. 图形表 `Icon` 字段生效。
5. 连续失败三次降级语义改为按失败序列起始等级计算。
6. 卡牌动画与提示动画补齐到策划描述。
7. 增加接口说明、修复说明、静态校验脚本。

## 2. 关键修复明细

### 2.1 训练结束传参

新增 `shared/game.js -> emitTrainingResult()`。

训练结束时输出：

- `passFlag`：`1` 表示已通关，`0` 表示未通关。
- `passed`：布尔通关标识。
- `passText`：`已通关` / `未通关`。
- `totalScore`：训练总分。
- `startLevel`、`finalLevel`：起始与结束难度。
- `assignedTrainingSeconds`、`usedTrainingSeconds`、`remainingSeconds`：训练时间。
- `history`：小关记录。

传出方式：

- `window.KX_onTrainingEnd(payload)`
- `window.dispatchEvent(new CustomEvent("KX_TRAINING_END", { detail: payload }))`
- `window.parent.postMessage({ type: "KX_TRAINING_END", payload }, "*")`
- `localStorage.KX_LAST_TRAINING_RESULT`

接口文档见包内 `docs/接口说明.md`。

### 2.2 自动继续训练

原版本需要点击“继续”才能进入下一小关，且结算弹窗期间总训练时间不消耗。修复后：

- 总训练倒计时由全局计时器维护。
- 小关结束后只显示短暂结算浮层。
- 总训练时间未到 0 时自动进入下一小关。
- 总训练时间到 0 时立即结束训练并传出结果。
- 用户仍可点击“立即继续”提前进入下一小关。

### 2.3 通关目标字段

打磨版运行时优先读取 `TargetCount`。

兼容逻辑：若旧表未提供 `TargetCount/TargetNum`，才回退为：

```text
ceil(Scores / Score)
```

本包已给儿童版、成人版 50 关全部补齐 `TargetCount`。

### 2.4 图形范围字段

打磨版运行时优先读取关卡级范围：

1. `ShapeRange: [min, max]`
2. `ShapeMin + ShapeMax`
3. `RangeStart + RangeEnd`
4. 回退到 `Type -> shapeRanges`

当前范围：

- Type 1：1–30
- Type 2：31–62
- Type 3：63–100

### 2.5 Icon 字段

原版本使用 `shape.ID` 拼接 `assets/shapes/shape_###.svg`。打磨版改为优先使用图形表 `Icon` 字段：

```text
assets/icons/{Icon}.svg
```

已补齐：

- `assets/icons/Icon1.svg` 至 `Icon100.svg`
- `assets/icons_png/Icon1.png` 至 `Icon100.png`

`assets/shapes/shape_###.svg` 与 `assets/shapes_png/shape_###.png` 保留为兼容备用。

### 2.6 失败三次降级

打磨版按连续失败序列的起始等级计算：

- 第 1 次失败：原难度继续。
- 第 2 次失败：起始等级 -1。
- 第 3 次失败：起始等级 -3，并清空失败计数。
- 最低等级为 1。

示例：从等级 10 连续失败三次：

```text
10 -> 10 -> 9 -> 7
```

不再出现旧逻辑中的：

```text
10 -> 10 -> 9 -> 6
```

### 2.7 动画修复

- 卡牌进入：从右侧飞入中间。
- 卡牌结束：从中间向左侧飞出。
- 正确/错误提示：从 3 倍缩放到 1 倍，停顿后淡出。

对应文件：`shared/style.css`。

## 3. 保留与未擅自修改项

上传文件只提供了一套 50 关数值表。打磨版保留儿童版与成人版两个入口、两个独立 `levels` 数组，但不自行编造成人/儿童差异数值。若后续提供成人原表或儿童修改表，可直接替换：

- `shared/data.js -> versions.child.levels`
- `shared/data.js -> versions.adult.levels`
