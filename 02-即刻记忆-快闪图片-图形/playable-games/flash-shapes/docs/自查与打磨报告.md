# 快闪图形·打磨版 自查与打磨报告

## 1. 自查结论

在修复版基础上继续检查后，核心设计逻辑已经闭合：成人版/儿童版入口、三档难度入口、50 级关卡、N/M 通关目标、连续选错两次结束小关、倒计时为 0 结束小关、通关后继续训练到总训练时间为 0、升降难度、积分公式、通关标识传参、帮助页红字、图形表与图形范围均已保留。

本轮主要打磨的是运行稳定性、素材加载流畅度、异常回退、暂停体验、接口安全配置、可访问性和回归校验覆盖范围；本次追加了三档难度选择：容易从第 1 关开始，普通从第 15 关开始，困难从第 30 关开始。

## 2. 本轮新增打磨项

| 类别 | 打磨内容 | 影响文件 | 说明 |
|---|---|---|---|
| 难度选择 | 新增三档难度 UI 与状态传参 | `儿童版/index.html`、`成人版/index.html`、`shared/game.js`、`shared/data.js` | 容易/普通/困难分别固定从第 1/15/30 关开始；训练中继续按升降级规则动态变化。 |
| 计时稳定性 | 新增 `runId` 与 `levelEndTimeoutId` | `shared/game.js` | 避免旧小关的延迟回调在重新训练、返回设置、重进引导后误触发。 |
| 暂停体验 | 新增 `pauseQuestionDelay()` / `resumeQuestionDelay()` | `shared/game.js` | 暂停时保留“记忆卡/下一题”的剩余等待时间，恢复后继续原等待，不再粗暴改成 250ms。 |
| 素材流畅度 | 新增 `preloadCriticalAssets()` | `shared/game.js` | 预加载标题、背景、帮助图、小康康和 100 个 Icon SVG，减少首轮出题时的图形闪烁。 |

| 回归测试 | 扩展 `tests/verify_static.mjs` | `tests/verify_static.mjs` | 新增静态资源引用检查、打磨函数存在性检查。 |

## 3. 不变项

本轮没有改变以下玩法口径：

- 小关结束条件仍为连续选错两次或倒计时为 0；总训练时间为 0 时结束训练。
- 通关条件仍为 `实际正确数 >= TargetCount`。
- 未通关仍固定获得 10 分。
- 通关积分仍为 `round(Scores + (实际数 - TargetCount) * Score + 10)`，并兼容 `PassScore/RewardScore` 字段。
- 通关升一级；失败第 1 次不降，第 2 次相对失败序列起始等级 -1，第 3 次相对失败序列起始等级 -3 并清空。
- 图形渲染仍优先读取 `Icon` 字段，图形池仍优先读取关卡级 `ShapeRange`。
- 成人版与儿童版继续保留独立入口和独立关卡数组；由于当前只提供一套 50 级数值，没有编造两版差异。

## 5. 后续仍可继续精修的点

这些不是当前验收阻断项，但如果要进一步接近正式商用交付，可以继续做：

1. 接入真实美术输出的逐帧小康康动画，而不是当前 SVG 状态图 + CSS 动效。
2. 用真实音效替换当前程序化/轻量 WAV 音频。
3. 如果平台能提供确切接口规范，可把 `payload` 字段名调整成平台字段名，并把 `postMessageTargetOrigin` 固化为正式域名。
4. 如果后续拿到“成人原表”和“儿童修改表”两套配置，应替换 `versions.adult.levels` 与 `versions.child.levels`，不再共用当前一套数值。
5. 如需严肃无障碍验收，可追加屏幕阅读器实测、色弱对比度校验和完整键盘焦点流测试。
