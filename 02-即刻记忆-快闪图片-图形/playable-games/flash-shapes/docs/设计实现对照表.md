# 设计实现对照表（打磨版）

| 需求 | 修复后实现位置 | 验收口径 |
|---|---|---|
| 儿童版 1、成人版 1 | `儿童版/index.html`、`成人版/index.html` | 两个独立入口，根目录 `index.html` 做版本选择。 |
| 开机动画展示角色小康康 | 欢迎页 `xkk_wave.svg`，CSS `mascot-bob` | 进入游戏先显示小康康与《快闪图形》标题。 |
| 标题《快闪图形》 | `assets/ui/title_logo.svg` | 欢迎页、入口页共用。 |
| 欢迎动画与标题相同 | 欢迎页复用标题 LOGO 与开场缩放/高光动画 | 保持标题一致。 |
| 主角动画 | `assets/mascot/` 多状态 + CSS 动画 | 小康康有 idle、wave、happy、blink、think、sad 六套状态。 |
| 软件切图 | `assets/ui/`、`assets/mascot/`、`assets/shapes/`、`assets/icons/`、`assets/audio/` | 含 UI、图形、角色、音频、素材清单。 |
| 三档难度：容易/普通/困难 | `儿童版/index.html`、`成人版/index.html`、`shared/game.js -> selectDifficulty()` | 训练前只提供三档选择：容易从第 1 关开始，普通从第 15 关开始，困难从第 30 关开始；进入训练后继续按升降级规则动态变化。 |
| 游戏界面原积分位置改为 N/M | `shared/game.js -> updateHUD()` | `targetCounter` 显示 `实际正确数/目标数`。 |
| 帮助界面对应描述改为红字 | `help_rule_card.svg` 与 `helpOverlay .help-red` | “连续选错两次会导致关卡失败结束哦”为红字。 |
| 新增图形表 | `shared/data.js -> shapes` | 100 个图形记录，含 `ID/Color/Shape/Texture/Icon`。 |
| Icon 字段用于渲染 | `shared/game.js -> renderShapeImg()/resolveIconSrc()` | 优先加载 `assets/icons/{Icon}.svg`；本包已补齐 `Icon1.svg` 至 `Icon100.svg`。 |
| 新增图形挑选范围字段 | `shared/data.js -> ShapeRange`，`shared/game.js -> getShapeRange()/getShapePool()` | 每关优先读 `ShapeRange`；无关卡级范围时才按 `Type` 回退。 |
| 连续选错两次结束小关 | `shared/game.js -> handleAnswer()` | 第二次连续错误立即 `endLevel("连续选错两次", true)`，该小关判未通关。 |
| 倒计时为 0 结束小关 | `shared/game.js -> tick()` | 本关倒计时为 0 时结算当前小关。 |
| 总训练时长为 0 后结束训练 | `shared/game.js -> tick()/finishTraining()` | 总训练倒计时独立运行，归 0 后结束训练。 |
| 通关后若训练时长未耗尽则继续 | `shared/game.js -> showLevelResult()` | 小关结算浮层只短暂停留，之后自动进入下一小关，不再依赖手动点击。 |
| 传参通关标识 | `shared/game.js -> emitTrainingResult()`，`docs/接口说明.md` | 训练结束输出 `passFlag`、`passed`、`passText` 等字段，并附带 `difficultyId/difficultyLabel/difficultyStartLevel`。支持 `window.KX_onTrainingEnd(payload)`、`CustomEvent`、`postMessage`、`localStorage`。 |
| 积分公式 | `shared/game.js -> calcScore()` | 通关：`round(Scores + (实际数 - TargetCount) * Score + 10)`；未通关：固定 `10`。兼容 `PassScore/RewardScore` 字段。 |
| 升降难度 | `shared/game.js -> adjustDifficulty()` | 通关 +1；连续失败序列中第 1 次不降、第 2 次相对序列起始等级 -1、第 3 次相对序列起始等级 -3 并清空。 |
| 卡牌动画 | `shared/style.css -> @keyframes card-enter/card-exit` | 卡牌从右侧进入，结束时向左飞出。 |
| 正确/错误飘字动画 | `shared/style.css -> @keyframes float-up` | 提示由 3 倍缩放到 1 倍，停顿后透明消失。 |
| 测试钩子 | `shared/game.js -> window.KX_DEBUG` | 暴露目标数、积分、范围、Icon 路径和难度预览函数，便于后续回归。 |
| 素材预加载 | `shared/game.js -> preloadCriticalAssets()` | 标题、背景、帮助图、小康康与 100 个 Icon SVG 预加载，减少首轮闪烁。 |
| 图形失败兜底 | `shared/game.js -> attachCardFallback()/renderInlineShapeSvg()` | 缺失 Icon 时按图形表颜色/形状/纹理生成备用 SVG，不显示破图。 |
| 暂停延迟保护 | `shared/game.js -> pauseQuestionDelay()/resumeQuestionDelay()` | 暂停时保留下一题等待剩余时间，恢复后继续原等待。 |
| postMessage 目标域 | `shared/game.js -> POST_MESSAGE_TARGET_ORIGIN`，`docs/接口说明.md` | 默认兼容离线 `*`，正式接入可指定目标域。 |
| 可访问性与响应式 | `shared/style.css` | 焦点描边、低高度屏幕布局、减少动画偏好适配。 |

## 配置说明

当前上传的可执行配置只有一套 `data(1).json` / `P2快闪图形.xlsm` 关卡表；打磨版未擅自改动 50 关原始字段值。儿童版与成人版分别保留独立入口和独立 `levels` 数组，但字段值沿用上传表。若后续提供“成人原表”和“儿童修改表”两套不同数值，只需替换 `shared/data.js` 中 `versions.adult.levels` 与 `versions.child.levels`。
