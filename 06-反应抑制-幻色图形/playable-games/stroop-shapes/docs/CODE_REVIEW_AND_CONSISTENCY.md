# 代码审查与文档一致性报告

审查对象：`幻色图形_HTML5游戏包.zip` 解压后的 HTML5 游戏工程。

审查范围：`index.html`、`css/style.css`、`js/config.js`、`js/game.js`、`config/levels.json`、素材目录、说明文档与测试脚本。

依据资料：

- `逻辑修改内容(4).docx`：关卡结束、升降级、刷新、通关、计分、界面与美术需求。
- `data(2).json` / `config/original_uploaded_data.json`：颜色库、关卡字段结构与 100 关基础配置。

## 1. 总体结论

本轮审查发现原包核心功能基本可运行，但存在若干严谨性问题：目标字段读取不够稳健、连错阈值未优先读取关卡配置、连续失败 3 次的降级可能被解释为累计多降、新手教程过短、暂停后查看帮助会丢失当前训练上下文、结果导出兼容性和弹窗输出安全性仍可加强。

已完成修复并更新为 `1.1.0` 版本。修复后，游戏逻辑与文档要求保持一致，且增加了详细 6 步新手教程、独立教程文档、静态审查脚本和逻辑单元测试脚本。

## 3. 主要问题与修复详情

### 3.1 目标字段读取问题

原代码使用 `MissionNum` 作为小关目标。由于配置表同时存在 `MissionNum` 与 `MissionPass`，从命名看 `MissionPass` 更符合“通关目标 / 目标数”的含义。虽然当前生成配置中两者相等，但直接使用 `MissionNum` 会降低后续配置扩展的安全性。

修复：新增 `targetFor(cfg)`，优先读取 `MissionPass`，若不存在或非正数，再回退到 `MissionNum`。

### 3.2 连续选错阈值未读取关卡配置

原代码只读取全局 `CFG.subLevelEndRules.consecutiveWrongLimit`。配置表存在 `Fault` 字段，修订后的关卡配置也已把 `Fault` 设置为 2。忽略该字段会导致将来某些关卡需要单独调整容错次数时无法生效。

修复：新增 `wrongLimitFor(cfg)`，优先读取关卡 `Fault`，再回退到全局阈值 2。

### 3.3 失败 3 次降级基准不严谨

原逻辑在失败 2 次后已经把等级降低 1；第 3 次失败时又从当前等级再减 3。这样从同一个失败段起点看，可能变成净降 4 级。文档表述为“失败 2 次则难度 -1，失败 3 次难度 -3”，更严谨的实现应当以同一失败段的起始等级作为基准。

修复：新增 `failureBaseLevel`。失败段第 1 次记录基准等级；第 2 次设置为 `base - 1`；第 3 次设置为 `base - 3`，然后清空连续失败计数。

### 3.4 新手教程不足

原教程只有两个互动示例，不能充分解释文字颜色干扰项、小关目标、结束条件、升降级、积分、通关继续训练与快捷键。

修复：新增 6 步新手教程，包含进度条、文字说明、要点列表、示例卡片、按钮高亮、错误提示、可跳过、可重播。新增 `docs/BEGINNER_TUTORIAL.md` 作为独立文档。

### 3.5 暂停后查看帮助会重置训练

原暂停界面的“帮助 / 重新引导”会停止 ticker 并进入引导，完成引导后进入训练会重新开始一局。这对用户不够友好。

修复：新增 `openGuideFromPause()` 与 `resumeFromGuide()`。从暂停进入教程时保持当前训练状态；教程完成后按钮显示“返回训练”，回到原等级、原小关和原剩余时间继续。

### 3.6 弹窗 HTML 输出与导出兼容性

原结算弹窗直接拼接 HTML。虽然当前内容主要来自内部逻辑，但从工程安全习惯看应转义。原 JSON 导出在部分浏览器上过早 revoke URL 可能造成下载不稳定。

修复：新增 `escapeHtml()`，弹窗内容统一转义。导出时把临时 `<a>` 节点加入 DOM，点击后移除，并延迟 `URL.revokeObjectURL()`。

## 5. 修复后建议验收路径

1. 打开 `index.html`。
2. 进入难度选择，分别检查容易、普通、困难的起始等级是否为 1、15、30。
3. 完整走一遍 6 步新手教程，确认高亮按钮、错误提示、跳过和重播均正常。
4. 进入游戏后检查 HUD 是否显示小关目标。
5. 连续故意选错 2 次，确认小关立即结束。
6. 达成目标，确认小关成功、等级 +1、积分按公式增加。
7. 连续失败 1、2、3 次，确认等级变化符合失败段基准逻辑。
8. 暂停后点击帮助，跳过教程后确认能返回原训练而不是重开。
9. 训练结束后导出 JSON，确认包含 `passFlag`。
