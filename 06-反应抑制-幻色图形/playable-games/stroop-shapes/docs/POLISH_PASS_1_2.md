# 1.2.0 精细打磨记录

本轮目标：在不改变核心配置口径的前提下，提升界面可读性、暂停/切屏稳定性、训练结果可解释性和新手教程完整度。

## 1. 界面精细化

1. 主训练界面新增双进度条：
   - 训练剩余：对应整次训练时长。
   - 小关剩余：对应当前小关倒计时。

2. 主训练界面新增状态条：
   - `连错 0/2`：实时显示连续错误次数和本关阈值。
   - `还差 N 次达标 / 小关目标已达成`：实时显示目标完成状态。

3. 刺激卡片新增语义标签：
   - 左卡：`图形颜色`。
   - 右卡：`文字含义`。
   这样可以直接提示新手“看颜色”和“读文字含义”，减少把右侧字色当答案的误判。

4. 答案按钮新增快捷键可视提示：
   - `← / X` = 不一致。
   - `→ / Enter` = 一致。

5. 增加低动态偏好处理：系统设置为减少动态效果时，CSS 会大幅压缩动画时间。

## 2. 逻辑稳定性精修

1. 暂停时处理答题后的延迟过渡。
   - 原有实现中，玩家作答后会有短暂反馈动画，再刷新题目。
   - 如果玩家在这段过渡内暂停，理论上存在暂停界面打开后题目仍完成刷新或触发小关结算的风险。
   - 现已加入 `pendingTransition` 和 `transitionToken`，暂停期间不继续执行答题后的刷新/结算，恢复后再处理。

2. 页面切换自动暂停。
   - 当浏览器标签页切到后台时，如果训练正在进行，游戏自动进入暂停。
   - 这样可以避免用户不可见时训练倒计时继续消耗。

3. 结果数据扩展。
   - 小关结算新增：作答数、正确数、错误数、小关准确率。
   - 最终结果新增：总作答、总正确、总错误、总体准确率、最高到达等级、成功/失败小关数。
   - 导出的 JSON 同步包含这些字段。

## 3. 新手教程扩展

教程由 6 步扩展为 8 步：

1. 基础判断：比较左图颜色和右字含义。
2. 说明右字显示颜色是干扰项。
3. 不一致示例。
4. 常见陷阱：右字显示颜色与左图相同，但文字含义不同。
5. 再次训练忽略干扰色。
6. 解释小关目标、连错提醒和进度条。
7. 解释小关结束条件与升降级。
8. 解释难度、积分、通关和快捷键。

## 4. 不变项

本轮没有改变以下核心规则：

- 容易、普通、困难仍从第 1、15、30 关开始。
- 小关结束条件仍是倒计时归零或连续选错 2 次。
- 小关成功仍按 `实际完成数 ≥ 小关目标` 判断。
- 失败 1/2/3 次的降级规则不变。
- 成功/失败积分公式不变。
- 达到最高等级后的 `passFlag` 通关标识不变。
