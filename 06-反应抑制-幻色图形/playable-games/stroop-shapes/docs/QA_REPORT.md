## 逻辑覆盖清单

- 欢迎界面、难度选择、8 步新手教程、教程完成、主训练、训练/小关进度条、连错提醒、目标达成提醒、暂停、完成结算、训练结束界面已实现。
- 小关结束条件：倒计时为 0 或连续选错 2 次。
- 小关内刷新：答题后继续刷新题目，直到小关结束。
- 小关目标：HUD 显示 `实际完成数 / 小关目标`，状态条显示还差几次达标或目标已达成。
- 目标字段：优先读取 `MissionPass`，回退 `MissionNum`。
- 连错阈值：优先读取关卡 `Fault`，回退全局阈值 2。
- 升级：成功后等级 +1。
- 降级：失败 1 次原级；失败 2 次按失败段起点 -1；失败 3 次按失败段起点 -3 并重置失败计数；最低等级 1。
- 分数：成功按 `Score + (实际数 - 目标数) * Scores + 10`，失败固定 10 分。
- 通关标识：达到最高等级后 `passFlag=true`，训练继续至训练时长结束。
- 暂停帮助：可进入教程并返回当前训练，不强制重新开始。
- 暂停稳定性：作答反馈后的延迟刷新在暂停期间会挂起，恢复后继续处理。
- 页面切换：浏览器标签页切到后台时自动暂停训练。
- 动画：题目淡入/淡出约 0.2 秒；正确/错误提示约 0.4 秒；动画中锁定输入；支持低动态偏好。
- 素材：3 × 9 图形、Logo、按钮、HUD 图标、小康康、背景、音效与音乐均已打包。

## 浏览器验收建议

```bash
python -m http.server 8000
```
