# 数字阶梯｜三难度终检版

本版在“数字排版修复版”基础上继续修复并自测，新增三个难度入口，并重新处理移动端气泡布局碰撞。

## 直接运行

打开 `index.html` 运行游戏。打开 `asset_preview.html` 查看素材预览。查看 `三难度终检与自玩报告.md` 和 `qa_result.json` 核对本轮自玩与自动检查结果。

## 本轮需求落实

1. 增加三个难度入口：容易、普通、困难。
2. 容易从第 1 关开始，普通从第 15 关开始，困难从第 30 关开始。
3. 失败后的“重新挑战本难度”按所选难度起点计算相对难度组；普通不会回退到第 11 关，困难不会回退到第 26 关。
4. “重新训练”会回到当前所选难度的起始关卡。
5. HUD 改为“难度 / 关卡”，提示栏显示当前难度和当前关卡。

## 本轮额外打磨

1. 保留两位数完整文本 token 排版，避免 `12` 被拆成 `1  2`。
2. 增加移动端气泡碰撞解算与必要时的紧凑排布，避免同一行多个两位数或运算式气泡互相压住。
3. 针对 390×844、320×568、1024×768 三种视口扫描 100 关气泡位置，确认无重叠。
4. 自玩通过容易、普通、困难首关，并验证 1→2、15→16、30→31 的推进。
5. 自玩困难难度错误点击，确认失败弹窗与“重新挑战本难度”回到第 30 关。

## 目录

- `index.html`：三难度终检版游戏页面。
- `asset_preview.html`：素材总览预览页。
- `三难度终检与自玩报告.md`：本轮修复、自玩与检查摘要。
- `qa_result.json`：浏览器自玩与自动检查结果。
- `static_validation.json`：静态资源、脚本语法、数值配置和布局扫描摘要。
- `asset_manifest.json`：当前交付文件清单。
- `自玩_*.png`：本轮浏览器自玩截图。
- `assets/`：完整图片、音频、气泡、UI、图标和教程素材。
