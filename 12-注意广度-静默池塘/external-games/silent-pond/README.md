# 静默池塘｜二次打磨版实现说明

## 运行方式

直接打开 `index.html` 即可运行。项目不依赖外部网络或第三方库；视觉素材、UI 图标、按钮、面板、动画帧与 WAV 音效均位于 `assets/` 目录。

## 本轮修复摘要

1. 修复最后一条红鲤鱼投食成功后的结算竞态：命中全部红鱼后立即进入 `resolving` 状态，冻结输入、倒计时与剩余时间，动画结束后用冻结时间结算，避免“已完成投食但倒计时先归零失败”和少算 0.36 秒动画时间的问题。
2. 统一 `Fault` 语义：P2 表头为“容错率（可错）”，本版本按“允许错误次数”处理，即错误次数 `> Fault` 时失败。例如 `Fault=2` 表示第 1、2 次错误仍可继续，第 3 次错误失败。
3. 接入鱼体大小配置：运行时读取 `fishSize.redPercent`、`fishSize.blackPercent`，并兼容关卡级 `RedSize/RedPercent/RedFishSize/RedFishPercent` 与 `BlackSize/BlackPercent/BlackFishSize/BlackFishPercent` 字段；命中半径、边界、障碍碰撞、绘制缩放同步使用。
4. 统一对外命名为“干扰鲤鱼”，代码内部仍可保留 `BlackNum` 数值字段，界面不再混用“黑/绿鲤鱼”。
5. 精致素材进一步接入：HUD 图标、暂停图标、按钮图、玻璃面板、logo、池塘石框、黑绿色干扰鱼帧动画、涟漪/水花序列、环境循环音均纳入运行时。
6. 暂停后重新演示已改为可恢复原局：从暂停帮助进入引导时保存当前关卡状态，引导完成后可返回原关卡，恢复计时、鱼、投食、食物、错误次数、总分和趋势。
7. 投食弹道改为跟随目标鱼当前位置，降低高速移动时“食物落点与鱼身偏离”的视觉问题。
8. 重叠鱼点击改为按视觉上层判定：从鱼数组末尾向前命中，点击结果与后绘制的视觉上层一致。
9. 开局动画加入水面模糊叠加与强波纹；池塘内加入低频环境涟漪。
10. 通关继续支持外部平台接管：若设置 `SilentPondOnGameComplete/onSilentPondComplete` 回调或 `nextGameUrl`，可进入下一个游戏；单机版则回欢迎界面。

## 规范来源

- `静默池塘文档(1).xlsx`：简述、玩法说明、界面、动画、数值与关卡、素材需求表。
- `P2静默池塘(1).xlsm`：50 关正式关卡配置，已导出为 `data.json` 与 `data.js`。
- `静默池塘(1).rp`：Axure 原型文件。该文件为 Axure 私有包，当前实现以可读取的 Excel 规范和数值表为准。

## 已实现的核心规范

1. 训练目的：锻炼注意力广度。
2. 游戏流程：开场欢迎界面 → 新手引导 → 引导完成选择 → 正式训练 → 完成界面/通关界面。
3. 鲤鱼移动：鲤鱼按方向直线移动；达到变向时间后随机转向；碰到池塘边界和内部阻挡物反弹。
4. 投食操作：点击未投食过的红鲤鱼视为成功；食物从投食机飞向目标；投食机进入 CD；食物数量减少。
5. 错误判定：点击干扰鲤鱼或重复点击已投食红鲤鱼，食物飞出但食物数量不减少，错误次数 +1；错误次数超过本关可错次数时失败。
6. 完成判定：所有红鲤鱼都被投食一次后过关。
7. 计时判定：倒计时归零失败；全部红鱼完成后立即冻结倒计时用于结算。
8. 积分计算：`关卡积分 = Score + Scores × 剩余时间 / Time`；时间按 0.1 秒精度结算，积分四舍五入为整数。
9. 奖励判定：剩余倒计时达到 `Limit` 时显示 `Reward × RewardNum`。
10. 池塘生成：外围石框阻挡；内部根据 `Shade` 生成半透明遮挡/阻挡装饰；阻挡装饰层级高于鲤鱼，非阻挡装饰位于鲤鱼下方，避免目标识别被普通装饰干扰。
11. 动画与音效：开局强波纹与模糊、投食成功跳跃、水花、涟漪、失败扑腾、环境水声、按钮音、过关/通关音效；投食成功/失败水花位于鱼层上方，环境涟漪位于鱼层下方。
12. 界面：欢迎界面、引导完成界面、主游戏界面、完成界面、通关界面、暂停界面均已实现；暂停时主界面模糊处理，提供继续、音量、静音、帮助。

## 规范缺口与处理

- 数值文档列出了“变向时间上限/下限”和“红/黑鲤鱼大小”，但 `P2静默池塘(1).xlsm` 没有逐关字段。实现中在 `data.json` 顶层提供默认变向范围与鱼体百分比，并预留关卡级字段兼容。
- “黑鲤鱼/绿鲤鱼/黑绿色鲤鱼”命名已统一为“干扰鲤鱼”。数值字段 `BlackNum` 保留，是为了保持与 P2 表一致。
- 积分文字规则采用“四舍五入”；若文档示例中存在截断式结果，以文字规则优先。

## 文件结构

- `index.html`：游戏入口。
- `styles.css`：界面、HUD、弹窗、按钮与素材样式。
- `game.js`：游戏逻辑、动画、判定、绘制、音效。
- `data.js`：浏览器直接加载的 50 关配置。
- `data.json`：与宏表输出一致的配置文件，便于二次导入或校验。
- `assets/`：视觉、鱼、装饰、UI、FX、音频素材。

## 二次打磨补充

本版本在“精致 UI 重做版”基础上继续处理完成界面的生产感和运行细节：结果按钮改为进入结果面板内部的流式布局；得分趋势横轴从“分数值”修正为关卡序号；趋势线改为平滑曲线并增加节点数值；积分公式改为显示本关实际计算项；新增总分奖杯与奖励礼盒图标；普通装饰与阻挡装饰拆分绘制层级，降低普通装饰遮挡目标鱼的概率。


## 三难度入口

本版本新增三个难度入口：容易从第 1 关开始，普通从第 15 关开始，困难从第 30 关开始。欢迎界面可直接选择难度；新手引导完成后也可选择三档训练。
