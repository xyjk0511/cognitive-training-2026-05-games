# 静默池塘｜精致 UI 重做说明

本版本基于“精致修复版”继续修改，未重写关卡数据与核心玩法逻辑，重点只处理 HTML/CSS/结果弹窗结构与视觉层级。

## 本轮修改范围

1. 重做关卡完成/通关结果弹窗。
   - 原结果弹窗由通用 `.kvGrid` 小卡片和简易 SVG 折线组成，视觉层级弱、空间拥挤、完成界面缺乏正式游戏 UI 感。
   - 新版本改为 `.resultModal` + `.resultPanel` 专用结构，包含顶部青绿色缎带标题、四个结果信息卡、积分公式条和独立趋势图区域。

2. 改善整体 HUD 与底部投食机栏。
   - 顶部状态栏改为深青色玻璃胶囊样式，增强数字可读性。
   - 暂停按钮、普通按钮、投食机状态条统一金色/青绿色视觉语言。

3. 改善遮罩层与弹窗可读性。
   - 降低全屏遮罩的黑度，增加轻微背景模糊和水色高光，避免背景被压得过暗。
   - 结果弹窗宽度从通用 580px 扩展到 840px，避免信息拥挤。

4. 重做得分趋势图。
   - 原趋势图只有一条折线和底部数值。
   - 新趋势图加入坐标轴、网格、面积填充、节点高亮和更大的 SVG 画布。

5. 保持素材完整接入。
   - `index.html`、`styles.css`、`game.js` 共引用 50 个素材路径。
   - `assets/` 中 50 个素材均被引用；缺失 0 个，未使用 0 个。

## 未改动内容

- 50 关关卡数据未改动。
- 投食判定、计时、冷却、容错、分数公式、最后一鱼冻结时间等修复版逻辑未改动。
- 新手引导、暂停、帮助、失败、通关外部回调逻辑保持原修复版实现。

结果：运行时核心检查通过。

## 二次打磨追加

1. 结果弹窗按钮不再用负边距悬浮到面板底部，而是作为 `.resultActions` 插入 `.resultPanel` 内部，减少错位、重叠和不同视口下的漂浮感。
2. 趋势图横轴改为关卡序号；节点上方显示关键分数，避免把分数值同时当作横轴标签造成语义混乱。
3. 趋势图由 polyline 改为 cubic path，并加入渐变面积、节点 halo 和关键值标签。
4. 积分公式从泛化说明改为本关实际公式：基础分、时间奖励、剩余时间、关卡时间和最终分数同屏展示。
5. HUD 总分与结果奖励替换为专用奖杯/礼盒 SVG 图标，避免多个模块共用同一个星形图标。
6. Canvas 绘制层级拆分为：水面 → 环境涟漪 → 非阻挡装饰 → 鱼 → 投食弹 → 投食反馈水花 → 阻挡装饰 → 石框 → 投食机。
