# 精细打磨变更记录

本轮打磨基于 `fenmenbielei_game_review_fixed.zip`，不改变策划表规则、不改变 100 关配置、不改变三档难度起始关卡。重点提升界面完成度、首次游玩体验、交互反馈、容错和可维护性。

## 1. 界面与视觉层级

### 首页

- 增加素材加载进度条和百分比，避免用户在素材尚未完成加载时直接进入训练。
- 增加内容概览标签：`100 关`、`92 项物品素材`、`3 档起始难度`、`PassTarget 结算`。
- 调整背景光斑、玻璃拟态容器、按钮状态和焦点样式，使界面更像完整产品而非工程 Demo。

### 难度页

- 难度卡片补充训练定位标签，例如“基础分类”“二级类别”“高强度”。
- 增加底部 `30 秒上手` 说明，降低首次进入时的理解成本。
- 保持三个难度入口：容易第 1 关、普通第 15 关、困难第 30 关。

### 游戏页

- HUD 从 6 项扩展为 8 项，新增 `连错` 和 `轮次`。
- 提示区增加阶段标签：准备、观察、提示、选择、反馈。
- 选项卡增加数字角标，可对应键盘数字 1-4。
- 错误选择时，除红色标记错误项外，还用金色高亮本轮正确项，帮助新手形成规则反馈。
- 结算弹窗扩展为结果、积分、正确次数、准确率、剩余时间、等级变化，并显示本关计分解释。

## 2. 新手教程增强

- 首页、难度页和游戏页均保留教程入口。
- 游戏页新增 `本关准备` 遮罩：选择难度后先显示本关类别粒度、选项数量、倒计时和过关目标，点击“开始本关”后才真正启动倒计时。
- 教程弹窗从线性文字改为“4 张快速规则卡 + 详细步骤 + 积分说明”。
- 文档版教程继续保留在 `docs/BEGINNER_TUTORIAL.md`，并补充了新 UI、键盘操作和结算字段说明。

## 3. 交互与可访问性

- 增加键盘数字键 1-4 选择选项。
- 增加 Escape 快捷键：帮助弹窗打开时关闭弹窗；训练中暂停或继续。
- 增加 `aria-live` 状态反馈、按钮 `aria-pressed` 状态、弹窗 `aria-modal` 语义。
- 增加 `prefers-reduced-motion` 适配，降低动效敏感用户的不适。
- 增强焦点样式，方便键盘操作。

## 4. 代码稳定性

- 增加素材预加载函数 `preloadAssets()`。
- 增加统一的延迟任务管理：`scheduleRound()`、`scheduleStage()`、`clearStageTimeouts()`，降低旧轮次回调串场风险。
- 增加最近物品记录，优先避免图示和正确项短时间内重复出现。
- 增加 `scoreDetailsForStage()`，把计分计算和结算解释绑定，减少公式和显示不一致的风险。
- 增强暂停逻辑：暂停后选项按钮禁用，恢复后按当前阶段恢复可点击状态。

## 5. 校验与测试

- `tools/validate_project.py` 增加对新增 UI、文档和脚本的检查。
- 新增 `tools/playtest_simulation.py`，模拟每关 200 轮，共 20,000 轮，验证图示、正确项、干扰项和选项数量生成逻辑。
- 已运行：

```bash
python tools/validate_project.py
python tools/playtest_simulation.py
node --check src/game.js
node --check src/data.js
```

## 6. 未改变的核心规则

- 三个难度入口仍为：容易第 1 关、普通第 15 关、困难第 30 关。
- 小关结束条件仍为：倒计时为 0，或连续选错 2 次。
- PassTarget 仍只用于结算是否通关，不是即时结束条件。
- 通关等级 +1；失败 1 次原等级继续，失败 2 次等级 -1，失败 3 次等级 -3，最低第 1 关。
- 关卡计时、选项数量、基础分、奖励分和 PassTarget 仍来自源表生成的运行时数据。
