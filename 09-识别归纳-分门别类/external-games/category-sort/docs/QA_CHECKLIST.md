# QA 检查清单

该清单用于手工验收本地 HTML5 游戏包。建议每次修改 UI、逻辑或数据后按此清单复核。

## 1. 启动与素材

1. 解压游戏包。
2. 直接打开 `index.html`，或执行 `python -m http.server 8000` 后访问本地地址。
3. 首页应出现素材加载进度，加载完成后“进入训练”按钮可点击。
4. 康康、康康坐飞机、引导图、帮助图、整体效果图均能正常显示。
5. 如果浏览器允许音频，提示、正确、错误和结算音效应能播放；如果浏览器限制本地音频，不应影响游戏运行。

## 2. 难度入口

1. 容易应从第 1 关开始。
2. 普通应从第 15 关开始。
3. 困难应从第 30 关开始。
4. 难度选择后不应立即扣时间，应先显示“本关准备”遮罩。
5. 点击“开始本关”后倒计时才开始。

## 3. 单轮流程

每一轮应按以下顺序呈现：

1. 左侧先出现图示。
2. 图示移动。
3. 提示文字出现并播放提示音。
4. 右侧选项飞入。
5. 点击选项后出现正确或错误反馈。
6. 反馈结束后进入下一轮，除非触发小关结束条件。

## 4. 正确与错误反馈

1. 选对时，所选卡片应出现绿色高亮。
2. 选错时，所选卡片应出现红色高亮。
3. 选错时，本轮正确项应出现额外高亮。
4. 反馈文字应显示所选物品实际所属类别。
5. 选项按钮在反馈期间不可重复点击。

## 5. 结束与结算

1. 倒计时为 0 时应结算。
2. 连续选错 2 次时应结算。
3. 达到 PassTarget 后不应立即结算。
4. 通关时应升 1 级，最高不超过第 100 关。
5. 第 1 次失败应原等级继续。
6. 连续第 2 次失败应等级 -1。
7. 连续第 3 次失败应等级 -3 并清空失败计数。
8. 未通关固定获得 10 分。
9. 通关结算应显示计分解释。

## 6. 暂停、静音和键盘

1. 点击“暂停”后倒计时停止，选项不可点击。
2. 点击“继续训练”后倒计时恢复，选项恢复可点击。
3. 点击“静音”后音效不再播放，再次点击恢复。
4. 选项出现后，数字键 1-4 应能选择对应位置。
5. 训练中按 Escape 应暂停；弹窗打开时按 Escape 应关闭弹窗。

## 7. 自动校验

在工程根目录运行：

```bash
python tools/validate_project.py
python tools/playtest_simulation.py
node --check src/game.js
node --check src/data.js
```

四项均通过后再交付。
