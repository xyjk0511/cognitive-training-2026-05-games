# 《分门别类》新手教程

本教程面向第一次打开游戏的人，按实际游玩顺序说明每一步。游戏目标是：观察图示，听/看提示，在选项中选择与提示类别匹配的图片。

## 1. 如何启动

### 直接运行

解压游戏包后，双击 `index.html` 即可打开。

### 本地服务器运行

如果浏览器限制本地音频播放，可以在游戏目录运行：

```bash
python -m http.server 8000
```

然后在浏览器访问：

```text
http://localhost:8000
```

## 2. 首页怎么看

打开后先进入开机页。页面会显示游戏名称“分门别类”、训练类型、注意事项、康康形象和素材加载进度。

注意事项：该训练方案不适合色盲或色弱用户。

首页按钮：

- `进入训练`：素材准备完成后可点击，进入难度选择页。
- `新手教程`：打开教程弹窗。
- `帮助`：查看帮助图和核心规则。

首页的标签说明当前包包含 100 关、92 项物品素材、3 档起始难度和 PassTarget 结算规则。

## 3. 选择难度

游戏提供三个难度。难度只决定从第几关开始，不改变核心规则。

| 难度 | 起始关卡 | 适合对象 |
|---|---:|---|
| 容易 | 第 1 关 | 第一次玩、需要热身、希望从基础分类开始 |
| 普通 | 第 15 关 | 已理解规则，希望直接进入中段训练 |
| 困难 | 第 30 关 | 已熟悉玩法，希望从更高要求开始 |

点击难度卡片后，游戏进入训练页，但倒计时不会马上开始。页面会先显示“本关准备”。

## 4. 本关准备页怎么看

选择难度后会出现本关准备遮罩。它会显示：

- 类别粒度：一级类别、二级类别或三级类别。
- 选项数量：本关每轮出现几个选项。
- 倒计时：本关总时长。
- 过关目标：小关结束时至少需要正确几次。

确认后点击 `开始本关`，倒计时才会开始。

## 5. 一小关的完整流程

一小关由多个“选择轮次”组成。每一轮都会刷新图示和选项。

### 第一步：先看图示

游戏先显示一张图示图片。此时右侧选项还不会马上出现。你需要先观察图示是什么物品。

例：图示显示“鲨鱼”。

### 第二步：看提示、听提示音

图示移动后，提示文字出现，并播放提示音。

提示格式类似：

```text
请点击选择“动物”类的图片
请点击选择“脊椎动物”类的图片
请点击选择“鱼类”类的图片
```

提示中的类别就是本轮要找的类别。

### 第三步：选项飞入

提示出现后，右侧会飞入若干选项。选项数量由当前关卡配置决定，可能是 2、3 或 4 个。

每轮只有 1 个指定正确选项，其余是干扰项。图示和正确选项同类别，但不是同一张图片。

### 第四步：点击你认为正确的图片

点击后会出现反馈：

- 选对：所选卡片绿色高亮，并显示“正确”。
- 选错：所选卡片红色高亮；本轮正确项会额外高亮；反馈文字会显示你所选物品的真实类别。

选择后内容会刷新，进入下一轮。

## 6. 键盘怎么操作

选项飞入后，可以用鼠标点击，也可以按键盘数字：

| 按键 | 作用 |
|---|---|
| 1 | 选择第 1 个选项 |
| 2 | 选择第 2 个选项 |
| 3 | 选择第 3 个选项 |
| 4 | 选择第 4 个选项 |
| Escape | 训练中暂停；弹窗打开时关闭弹窗 |

如果当前关卡只有 2 或 3 个选项，超出范围的数字不会产生选择。

## 7. HUD 顶部状态怎么看

游戏页顶部显示 8 个状态：

| 字段 | 含义 |
|---|---|
| 难度 | 当前选择的入口难度 |
| 关卡 | 当前使用的关卡配置 |
| 积分 | 本轮训练累计积分 |
| 目标 | 当前正确次数 / PassTarget |
| 连错 | 当前连续选错次数 / 2 |
| 倒计时 | 本小关剩余秒数 |
| 轮次 | 本小关已经进行到第几轮 |
| 趋势 | 与上一次结算相比的表现趋势 |

## 8. 什么情况下小关结束

小关不是选对一次就结束，也不是达到目标次数立刻结束。

小关只在以下两种情况下结束：

1. 倒计时归零。
2. 连续选错 2 次。

这里的“连续选错”指没有被正确选择打断的连续错误。选对一次后，连续错误计数会清零。

## 9. PassTarget 是什么

每关有一个过关目标，界面上显示为“目标：当前正确次数 / PassTarget”。

例如：

```text
目标 2/3
```

意思是：当前已经正确 2 次，本关至少需要正确 3 次才算通关。

关键点：达到 PassTarget 后，小关仍会继续，直到倒计时结束或连续选错 2 次。继续答对可以获得超额正确奖励。

## 10. 结算怎么看

小关结束后会弹出结算窗口，包含：

- 结果：通关或未通关。
- 本关积分：本小关获得的分数。
- 正确次数：实际正确次数 / PassTarget。
- 准确率：正确次数 / 本小关轮次数。
- 剩余时间：小关结束时剩余秒数。
- 等级变化：结算前等级 → 结算后等级。
- 计分解释：说明本关分数如何计算。
- 趋势：与上一次结算比较后的提升、持平或下降。

### 通关

如果小关结束时正确次数达到 PassTarget，则通关，等级 +1。

### 未通关

如果小关结束时正确次数没有达到 PassTarget，则未通关。

失败等级规则：

| 失败次数 | 等级变化 |
|---:|---|
| 第 1 次失败 | 原等级继续 |
| 连续第 2 次失败 | 等级 -1 |
| 连续第 3 次失败 | 等级 -3，并清空失败计数 |

等级最低不会低于第 1 关。

## 11. 积分怎么算

### 未通关

未通关固定获得 10 分。

### 通关

通关分数由以下部分组成：

```text
基础分 * [1 + (选项数 - 2) / 10]
+ 剩余小关时长 * 2
+ (实际正确数 - 目标数) * 奖励分
+ 10
```

含义：

- 选项越多，难度越高，基础分倍率越高。
- 剩余时间越多，时间奖励越多。
- 超过目标次数的正确选择会得到额外奖励。
- 通关额外加 10 分。

结算弹窗中的计分解释会把这些项目直接展开。

## 12. 趋势是什么意思

趋势用于比较本次结算和上一次结算。

| 条件 | 趋势 |
|---|---|
| 本轮积分更高，且结算等级提高 | 提升 |
| 本轮积分不低，且等级不变 | 持平 |
| 本轮积分不低，但等级下降 | 持平 |
| 本轮积分更低，且等级下降 | 下降 |
| 本轮积分更低，但等级提高 | 提升 |

首次游玩时显示“初次”。

## 13. 暂停、静音、帮助

### 暂停

点击游戏页右上角“暂停”后，倒计时暂停，当前可点击选项会被禁用。点击“继续训练”后恢复。

### 静音

点击“静音”可以关闭提示、正确、错误和结算音效。再次点击可恢复声音。

### 帮助 / 引导 / 布局

- `帮助`：查看帮助图和核心规则。
- `引导`：查看固定引导图。
- `布局`：查看整体布局图。
- `新手教程`：查看分步说明。

## 14. 常见问题

### 为什么我已经达到目标，游戏还没结束？

这是正确规则。PassTarget 只用于结算是否通关，小关结束条件只有倒计时为 0 或连续选错 2 次。

### 为什么我选错一次后没有马上结束？

小关要求连续选错 2 次才结束。选错一次后，如果下一次选对，连续错误计数会清零。

### 为什么普通和困难不是从第 1 关开始？

这是需求指定：普通从第 15 关开始，困难从第 30 关开始。

### 为什么选项数量有时不同？

选项数量来自关卡数值表 `OptionalQuantity`。不同关卡可能有 2、3 或 4 个选项。

### 为什么图示和选项不是同一张图片？

策划要求图示与正确选项从目标池随机，但图示和正确选项不能重复。因此正确选项会与图示同类别，但不是同一张图片。

### 为什么我选错时另一个选项会亮起来？

这是本轮正确项提示，用于帮助用户理解错误原因。红色是你选错的选项，金色是本轮应选择的正确项。
