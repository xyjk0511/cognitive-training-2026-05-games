# 《眼疾手快》儿童版精致版

直接打开 `index.html` 即可运行；游戏不依赖外网，不需要安装第三方库。

## 本次升级重点

- 所有视觉素材均已自制并放入 `assets/`：小康康角色、普通地鼠、头盔地鼠、破裂头盔、炸弹、白猫、花猫、地洞、游戏背景、欢迎背景、UI 图标、通关彩带、软件图标和启动切图。
- `assets/software/` 已输出软件切图：`app_icon.svg`、`app_icon_512.png`、`app_icon_1024.png`、`launch_card.svg`、`launch_card_1280x720.png`。
- 主界面、开机动画、欢迎动画、暂停弹窗、结果弹窗均使用统一的施工场景风格。

## 逻辑实现

- 升级：小关结束时达成目标，难度 +1。
- 降级：未达标时，第 1 次失败保持原难度，第 2 次失败难度 -1，第 3 次失败难度 -3，并清空失败次数，最低降到 1 级。
- 小关结束：连续选错两次或小关倒计时 `time=0`。
- 通关后继续训练：达成目标后不提前结束整场训练，直到下发训练时长结束，并回传 `passFlag`。
- 分数：通关时 `floor(通关积分 + (实际数 - 目标数) * 奖励分 + 10)`；未通关固定 10 分。
- 游戏界面显示目标数 `N/M`。

## 配置

配置在 `config.js` 与 `config_data.json` 中。关卡保留原表 51 级结构，并新增 `passTarget` 字段。

儿童版降低通关积分与目标数、放慢出现速率、降低单批随机出现数量，并减少干扰物占比。

## 训练结果回传

训练结束时：

```js
window.gameResult
```

并派发：

```js
window.addEventListener('training-finished', event => console.log(event.detail));
```


## 修复版说明

本版修复头盔破甲不清空连续错误、通关后可手动结束、HUD 积分口径与正式结算口径不一致，以及炸弹缺少独立爆炸反馈等问题。

- HUD 显示“已结算积分 + 当前小关按正式公式推算的预计积分”；命中进度由 `N/M` 实时呈现，避免命中分和结算积分混用。


## 教程与视觉优化版新增内容
- 首页“自动引导新手教程”改为 9 步互动流程：目标识别、HUD N/M、普通地鼠、头盔地鼠、炸弹/猫干扰项、空洞错误、小关结束、积分公式、综合练习。
- 训练界面增加更强的面板层次、按钮高光、地洞悬停反馈、教程高亮指示、进度条和练习反馈。
- 原严格修复版核心逻辑保持不变：连续选错两次或 time=0 结束小关；达标后自动续训到训练总时长为 0；传出 passFlag；按正式积分公式结算。


## 终极打磨增强

本版本在教程美术优化版基础上继续增强：训练 HUD 新增目标进度条和连续错误警戒条；最终结果页新增通过率、最高命中、最近难度趋势；教程完成状态本地保存；素材预加载；窗口切换自动暂停；支持键盘 focus-visible、触控点击优化和 reduced-motion。


## 三档难度起始关卡

- 容易：从第 1 关开始。
- 普通：从第 15 关开始。
- 困难：从第 30 关开始。

每次正式训练开始时，会按所选难度档重置起始关卡；训练过程中仍按小关通过/失败规则自动升降级。
