# 素材清单

本包素材为自制矢量/位图素材，未引用外部网络素材。

## 角色

- `assets/characters/xiaokangkang.svg`：开机、欢迎与说明使用的小康康角色。
- `assets/characters/mole_normal.svg`：普通地鼠。
- `assets/characters/mole_helmet.svg`：头盔地鼠。
- `assets/characters/mole_helmet_cracked.svg`：头盔首次被击中后的破裂状态。
- `assets/characters/bomb.svg`：炸弹干扰项。
- `assets/characters/cat_white.svg`：白猫干扰项。
- `assets/characters/cat_tabby.svg`：花猫干扰项。

## 场景与 UI

- `assets/backgrounds/game_scene.svg`：训练场景背景。
- `assets/backgrounds/menu_scene.svg`：开机与欢迎背景。
- `assets/holes/hole.svg`：地洞。
- `assets/branding/logo.svg`：标题字《眼疾手快》。
- `assets/ui/*.svg`：计时、积分、目标、暂停、音效、音乐、帮助、通关彩带等图标。

## CSS 动效增强
- ambientDrift：背景环境光缓慢漂移。
- pointerPulse：教程点击指针。
- 教程安全/危险目标高亮、按钮高光、训练面板玻璃层次。
