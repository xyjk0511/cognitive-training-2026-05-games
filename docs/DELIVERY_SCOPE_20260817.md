# rc3-baseline.3 单线施工交付范围

## 本批可以用于什么

- 作为 A620-TRC-1.1 rc3 的实现级、对抗式评审基线；
- 生成或核对公共消息、游戏结果、执行结局、主控状态和训练包 Schema；
- 运行正常、暂停、截止、终止和故障流程的参考验证；
- 验证消息幂等、旧执行隔离、跨重启 reducer 恢复和提交握手；
- 验证正式结果与批次证据、PREPARE 配置及同步队列的事务边界；
- 构建、验证、A/B 激活和恢复不含真实游戏内容的示例 `.tpkg`；
- 为后续 Android/Kotlin 与 Cocos/TypeScript 接入提供同源状态机、DTO 边界和测试向量。

## 本批不能用于什么

- 不能安装到患者平板；
- 不能接收真实患者任务；
- 不能代替 Android 总控、Cocos 运行环境或管理软件；
- 不能称为《捕光行动》或《信号反应站》可玩版本；
- 不能使用包内 RFC 8032 测试密钥签署生产训练包；
- 不能把参考 SQLite/A/B 槽测试等同于 Android Room、Binder、真实闪存断电验证；
- 不能据此把 Gate 0 标成通过。

## 下一施工闸门

Gate A/B 的目标是把当前参考约束接入真实工程：一个 Android APK、一个主控运行域、一个 Cocos 训练运行域、AIDL/Binder、Room 事务边界、原生触摸门和 MockGame。完成前不进入两款游戏代表等级。
