# 首批单线施工交付范围

## 本批可以用于什么

- 作为 A620-TRC-1.1 rc3 的实现级评审基线；
- 生成/核对公共消息、游戏结果、执行结局、主控状态和训练包 Schema；
- 运行正常、暂停、截止、终止和故障流程的参考验证；
- 为下一批 Android/Kotlin 与 Cocos/TypeScript 接入提供同源状态机和测试向量；
- 构建并验证不含真实游戏内容的示例 `.tpkg`。

## 本批不能用于什么

- 不能安装到患者平板；
- 不能接收真实患者任务；
- 不能代替 Android 总控、Cocos 运行环境或管理软件；
- 不能称为《捕光行动》或《信号反应站》可玩版本；
- 不能使用包内 RFC 8032 测试密钥签署生产训练包；
- 不能据此把 Gate 0 标成通过。

## 下一施工闸门

Gate A 的唯一目标是把当前参考约束接入真实工程：一个 Android APK、一个主控进程、一个 Cocos 训练运行区域、AIDL/Binder、Room 事务边界、原生触摸门和 MockGame。完成前不进入两款游戏代表等级。
