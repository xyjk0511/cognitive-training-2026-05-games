# W2 资产状态

## 已纳入训练包

原产品 ZIP 提供的 BG01–BG08 八张 1600×1000 PNG 背景已复制到 `packages/catch-light/content/assets/backgrounds/`，并在 `index.json` 中记录原文件名、尺寸和 SHA-256。会话固定使用起始代表级背景，不随批次变化。

## 仍为占位引用

12 种水果已经冻结 ID、中文名、主色、轮廓、纹理、相似标签以及目标/干扰许可，但工作包没有提供可交付水果 sprite。`assets/fruits/*.png` 是 Cocos 资产线待补路径，不在 W2 包内伪造近似美术。

以下内容也不在 W2 交付范围：

- Cocos Creator 场景、Prefab、对象池和触控节点；
- HUD、规则引导、暂停页、结算页；
- 收集/误触反馈动画与音效；
- 启动页和管理端展示图的运行时切图；
- Android/Cocos 真机触摸、帧率、内存和渲染验证。

因此 W2 可验证的是纯领域逻辑、确定性内容计划、正式结果和包内配置，不应被标记为可直接上线的视觉训练包。
